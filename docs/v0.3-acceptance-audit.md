## Architectural decisions and limits

Keep Next.js App Router, TypeScript, the typed catalog, static prerendering, and the shared trace player. Keep lesson/project content in data and reuse the existing assessment components. Project progress stays independent of V1 reading completion. No dependencies or runtime execution services were introduced by this audit.

The browser evaluates fixed reasoning choices; learners implement and run Python locally. Project checklists are self-reported. Reading completion and correct fixed choices do not establish mastery. Lesson attempts reset on reload; project reasoning/checklists persist in this browser and origin. Authored traces are finite examples rather than an interpreter, and desktop/mobile Chromium tests do not establish screen-reader, cross-browser, or educational certification.

Recommended V0.4 remains concept-tagged assessments with transparent knowledge-gap diagnosis, delayed retrieval practice, targeted review links, and an independent project variation with a rubric. Obtain human educational/accessibility review before building a larger adaptive system or expanding the curriculum.
