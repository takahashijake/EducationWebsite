## Limits and V0.3 direction

39 topics remain planned, including Recursion and Basic Debugging. Traces use authored snapshots and a small fixed input catalog; practice uses deterministic choices. There is no interpreter, free-form code grading, backend, authentication, cloud sync, or automatically verified mastery. Attempts are transient and completion remains manual/browser-local.

Automated regression checks and screenshot inspection do not establish independent educational review, screen-reader certification, or Firefox/WebKit coverage. Beginner walkthroughs, assistive-technology review, and additional browser testing remain useful follow-up work.

For V0.3, complete Basic Debugging and Recursion, add a modest guided project combining the five core lessons, and use beginner/accessibility feedback to improve pacing and feedback before adding more interaction models.
