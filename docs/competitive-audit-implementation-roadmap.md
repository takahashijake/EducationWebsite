# Remaining competitive-audit implementation roadmap

V1.7 addresses authored misconception recovery for one skill, a contextual lesson next step, returning-learner signal context, and planned-topic routing. V1.8 adds one integrated Dijkstra settled-distance journey with prediction, explanation, the existing Python Code Lab, a new network, and a delayed negative-edge revisit. The October audit remains the product evidence base. Release order is indicative and subject to human learning and accessibility review.

Do not treat automated correctness tests as evidence of improved learning outcomes.
